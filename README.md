# 📚 Velvet Pages - Dark Romance Reading Platform

A stunning, immersive dark romance book reading platform with beautiful UI, page-turn animations, and community features.

## 🎨 What's Been Built (Phase 1)

### ✅ Completed Features

1. **Landing Page** (`/`)
   - Dark aesthetic theme (burgundy, black, gold)
   - Animated background elements
   - Hero section with gradient text
   - Features showcase
   - Stats display (books, readers, pages read)
   - CTA section with pricing
   - Fully responsive design

2. **Library Page** (`/library`)
   - Beautiful book grid with hover effects
   - Book cards with gradient covers
   - Ratings, stats, and tags
   - Filter system
   - Animated interactions

3. **Reading Interface** (`/book/[id]`)
   - **3D page-turn animations** 🔥
   - Settings panel (font size, reading mode, ambient sounds)
   - Progress tracking
   - Keyboard navigation
   - Reader reactions preview

## 🚀 Run the App

```bash
npm run dev
```

Visit: **http://localhost:3000**
